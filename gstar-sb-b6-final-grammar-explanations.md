## The test applied

Could an 11–12-year-old at B1 learn the point from the box alone? That needs:

- **plain words** the student already knows, with no untaught terms (*assumption*, *source*,
  *clause*, *emphasis*);
- **a pattern they can copy**;
- **the one rule that prevents the usual mistake**, with a right/wrong pair if needed.

**Must fix** means wrong as printed: a false rule, a contradiction, or an error inside a model
sentence. **Should fix** means a recommendation: the box is correct but a student would struggle to
learn from it. The final wording is the owner's decision. Ids are `SB6F-Gnn`.

## Coverage: does each text model each grammar point?

✓ means the point is used correctly and a student can see it. ✘ means it is used wrongly; the id
of the error is in report 1 or 2. **Visible**, for the subjunctive, means a he/she/it subject, *be*,
or *not* + verb: `I suggest that you go` looks like the ordinary present.
